# Product steering: The Last Lantern

## Product
A short, browser-based haunted-house escape game called **The Last Lantern**. The player explores Blackthorn House, gathers a few useful objects, follows environmental clues, and escapes before a five-minute candle timer runs out.

## Audience and tone
- Designed as an easy-to-understand, self-contained mini-game for a global hackathon audience.
- Use concise English copy, atmospheric but not graphic horror, and a slightly literary tone.
- Make the first action obvious. A player should understand the objective within a few seconds.

## Product principles
- Keep the game playable offline with no account, paid service, external API, or network dependency.
- Prefer a small number of meaningful interactions over a large map or long story.
- Preserve keyboard access, visible focus, readable contrast, responsive layouts, and reduced-motion preferences.
- Keep progress local to the browser and offer an obvious restart.
- Never imply that Kiro was used unless the code was actually developed or changed in Kiro.

## Current state
The current `index.html` is an initial manually created prototype. The `.kiro` planning files are also initial notes, not a record of Kiro-generated work. Continue the implementation and tests in the actual Kiro application before describing the project as Kiro-built.
